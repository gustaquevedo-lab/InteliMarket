0

Materiales, antes de arrancar

lo que tenés que tener sobre la mesa

  • El Minisforum X1 Lite, con monitor y teclado conectados (solo para instalar; después queda headless).
  • Un pendrive de 8 GB o más — se borra por completo.
  • Cable de red al switch Unifi. Un nodo servidor va cableado, nunca por WiFi.
  • Ideal: una UPS pequeña para el Minisforum y el servidor legacy. Es lo que de verdad te protege ante cortes durante la cosecha de datos.

4

Instalar Ubuntu Server 26.04

booteá el Minisforum desde el USB — F7 o F11

  • Idioma: English para el sistema · Teclado Spanish (Latin American).
  • Red: dejá DHCP por ahora (fijamos la IP en el Paso 5).
  • Perfil: usuario gustavo, equipo minisforum-ia, contraseña fuerte (guardala en tu gestor).
  • “Install OpenSSH server” → marcalo. Esto es lo que habilita conectarte vía SSH después.
  • “Import SSH identity” → dejalo en No. Es opcional (importa una clave desde GitHub/Launchpad); las claves las configuramos después. La primera vez entrás con usuario + contraseña.

En la pantalla de almacenamiento, esta es la elección clave:

Guided storage configurationUbuntu Server · Installer
Use an entire diskusar el disco completo del Minisforum
✓ Set up this disk as an LVM groupflexibilidad + snapshots para respaldos
Encrypt with LUKSdejar SIN marcar — un server headless no debe pedir contraseña en cada reboot

Pantalla de almacenamiento del instalador: disco completo + LVM, sin cifrado manual.

Confirmá, dejá que instale, elegí “Reboot Now” y quitá el USB.

5

Blindaje base del sistema

primer arranque — por SSH o en el propio equipo

gustavo@minisforum-ia ~
# Actualizar todo el sistema
$ sudo apt update && sudo apt full-upgrade -y

# Parches de seguridad automáticos (se cura solo)
$ sudo apt install -y unattended-upgrades
$ sudo dpkg-reconfigure --priority=low unattended-upgrades

# Firewall: bloquear todo lo entrante salvo SSH
$ sudo apt install -y ufw
$ sudo ufw default deny incoming
$ sudo ufw default allow outgoing
$ sudo ufw allow OpenSSH
$ sudo ufw enable

# Herramientas base
$ sudo apt install -y git curl wget htop tmux build-essential
6

IP fija y acceso remoto

reserva en el Unifi + Tailscale

IP fija: en el controlador Unifi → Client Devices → minisforum-ia → Fixed IP (ej. …​.10). Reservarla en el Unifi es más robusto que configurarla a mano en el equipo.

Instalar Tailscale en el nodo
$ curl -fsSL https://tailscale.com/install.sh | sh
$ sudo tailscale up
# abrí el link que aparece para autenticar
# después: ssh gustavo@minisforum-ia  desde cualquier lado
!

Cuando Tailscale ya funcione, avisame y te paso el endurecimiento final de SSH (solo por clave, sin contraseña). Lo hacemos con cuidado para no dejarte afuera por error.

7

Instalar el stack de trabajo

Docker · Python (uv) · Node · Claude Code · Playwright

gustavo@minisforum-ia ~
# Docker — para levantar un MySQL propio donde restaurar el volcado
$ curl -fsSL https://get.docker.com | sudo sh
$ sudo usermod -aG docker $USER   # reiniciá sesión luego

# Python moderno con uv
$ curl -LsSf https://astral.sh/uv/install.sh | sh

# Node.js LTS (lo usan Claude Code y Playwright)
$ curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
$ sudo apt install -y nodejs

# Claude Code
$ sudo npm install -g @anthropic-ai/claude-code

# Playwright + navegador headless
$ mkdir -p ~/casa-gonzalito && cd ~/casa-gonzalito
$ uv init && uv add playwright
$ uv run playwright install --with-deps chromium
